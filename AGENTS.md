# pi-tweaks

## Architecture

- Keep each extension self-contained.
- Follow `docs/design.md` for conventions shared by all extensions.

## Development

- Read `justfile` before running commands.
- Use Oxc for lint, type checking, and formatting. Do not add ESLint or
  Prettier.

## Rules

- README.md should list only the extensions and their descriptions. An extension
  name may link to that extension's own README.
