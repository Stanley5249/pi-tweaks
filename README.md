# pi-tweaks

- **Catppuccin** (`/catppuccin`): Bundled Catppuccin themes for every flavor and
  a command to switch between them.
- **Context** (`/context`): Inspect the system prompt in a scrollable viewer,
  record a snapshot in chat, or copy and save the original text.
- **Statusline** (`/statusline`): Theme-aware footer with session usage, cache
  hit rate, context usage, and model information.
