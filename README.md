# pi-tweaks

- **Context** (`/context`): Inspect the system prompt in a scrollable viewer,
  record a snapshot in chat, or copy and save the original text.
- **Fast mode** (`/fast`): Manage OpenAI priority service tier for interactive
  requests.
- **Statusline** (`/statusline`): Catppuccin footer with session usage, cache
  hit rate, context usage, and model information. `/catppuccin` switches
  flavors.
